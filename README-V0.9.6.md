# SVCP Directorio Médico v0.9.6

## Novedades
- Indicador de pendientes junto a «Pagos de membresía» en el menú del administrador.
- Formulario de reporte de pago con carga obligatoria de captura del comprobante.
- Comprobante permitido: JPG, PNG o WebP, máximo 5 MB; validación de MIME y carga mediante la biblioteca segura de medios de WordPress.
- La captura queda asociada al reporte y se puede abrir desde la tabla administrativa.
- Notificación HTML mejorada al administrador con datos del pago, botón para ver el comprobante y botón para revisar/decidir el reporte.
- Se mantiene la verificación manual; enviar un reporte no activa automáticamente la membresía.

## Actualización
Realiza una copia de seguridad de los archivos y la base de datos antes de actualizar. Después de instalar, prueba un reporte con una cuenta de doctor y verifica que la captura aparezca en el panel de Pagos de membresía.
