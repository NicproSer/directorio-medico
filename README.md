# SVCP Directorio Médico

**Versión:** 1.0.7  
**Autor:** NICPRODEV  
**Plataforma:** WordPress

Plugin para administrar el directorio público de médicos de la Sociedad Venezolana de Coloproctología (SVCP), las cuentas de los doctores, la aprobación de fichas, las membresías y los reportes de pago.

## Documentación

- [Manual del administrador](MANUAL-ADMINISTRADOR.md)
- [Manual del usuario final (médico)](MANUAL-USUARIO.md)

## Actualización a 1.0.7

Esta versión incorpora consulta de divisa opcional (no bloqueante), comprobante PDF con identidad institucional y RIF, y publicación automática de la ficha al aprobar un pago. Consulta los manuales actualizados para el médico y el administrador/tesorero.

## Recomendación de actualización

Antes de actualizar, realiza una copia de seguridad de la base de datos y de los archivos de WordPress. Actualiza el plugin desde el paquete de la versión 1.0.0 y verifica las páginas públicas, los ajustes de membresía, el envío de correos y los reportes de pago. Si WordPress no reconoce los enlaces permanentes, entra en **Ajustes → Enlaces permanentes** y pulsa **Guardar cambios** sin modificar necesariamente la estructura.
